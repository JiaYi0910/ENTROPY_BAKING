# 熵與焙 ENTROPY & BAKING

精選咖啡豆網站：客人在前台瀏覽豆單、加入購物車下單、申請 VIP 儲值，並用 LINE 登入查看自己的訂單；管理員在後台管理商品、訂單與儲值會員。
資料存在 Firebase（免費方案），網站放在 GitHub Pages。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html`、`style.css`、`script.js` | 前台：豆單、搜尋篩選、公告、VIP 儲值方案 |
| `order.js` | 前台購物車、結帳、申請儲值 |
| `line-login.js` | 客人用 LINE 登入（LIFF） |
| `my-orders.js` | 前台「我的訂單」：客人查看自己的訂單與狀態 |
| `pricing.js` | 價格、耗材、運費、儲值方案的計算規則（前台與後台共用） |
| `admin.html`、`admin.js` | 後台：登入、商品管理（網址：網站網址後面加 `/admin.html`） |
| `admin-shop.js` | 後台：訂單管理、儲值會員、商店設定、新訂單通知 |
| `firebase-config.js` | Firebase 專案設定，前台和後台共用 |
| `firestore.rules` | Firestore 安全規則（要貼到 Firebase 主控台才會生效） |
| `notify/` | Google 小幫手（Apps Script）：Email 通知、LINE 登入、LINE 訊息，與設定說明 |

## 客人的購物流程

1. 豆單按「**加入購物車**」→ 選加工方式（原豆／研磨／浸萃包／濾掛包）、份量（1 磅／半磅）、數量。
2. 右上角 🛍 **購物車** → ① 確認品項 → ② 選取貨方式（門市自取／全家店到店／宅配）、填資料、選付款方式（銀行轉帳／儲值金扣款）→ ③ 訂單完成，顯示訂單編號與轉帳帳號。
3. 轉帳後用 LINE 回報帳號後五碼（完成頁有按鈕會自動帶入訂單編號）。
4. VIP 儲值方案按「**我要儲值**」可直接申請，電話就是儲值會員帳號。
5. 右上角 👤 **我的訂單**：用 LINE 登入後可查看自己所有訂單與目前狀態，後台改狀態時會即時更新。

開啟 LINE 登入後（見下方「Email 與 LINE 通知」），結帳、查訂單、申請儲值時會先用 LINE 登入，只瀏覽豆單不需要登入。下單後與付款、出貨、取消、儲值完成時，LINE 機器人會自動傳訊息給客人。

訂單一律從網頁送出。萬一送出失敗（例如網路問題），畫面會請客人再按一次，並顯示錯誤代碼方便店家查原因。

## 後台使用說明

- **📦 訂單管理**：新訂單會即時出現並發出提示音；可改狀態（待付款 → 已付款 → 已出貨 → 已完成／已取消）、填匯款後五碼與管理備註。
  - 系統會用目前價格重新核對金額，對不上時會顯示 ⚠ 提醒。
  - **儲值申請**：確認收到轉帳後按「確認入帳並加值」，自動加值到客人的儲值金。
  - **儲值金扣款的訂單**：按「從儲值金扣款」，自動扣除餘額並改為已付款。同一筆不會重複加值或扣款。
- **👛 儲值會員**：每位會員的餘額與交易紀錄；客人在門市直接儲值時，可用「手動加值／扣款」登記。
- **⚙️ 商店設定**：轉帳帳號、運費、耗材費、Email 通知網址、LINE 登入（LIFF ID），儲存後前台立即套用。
- **用 LINE 登入的客人**：訂單的「客人資料」會顯示「LINE ✓」，改狀態儲存後會自動傳 LINE 通知給客人。
- **商品**：「前台排序」數字越小越前面；「半磅價格」不填會自動用 1 磅價格的一半。
- **產地**：盡量從建議清單選擇，名稱要跟前台「產地篩選」一致（例如「臺灣」不是「台灣」）。

## 安全規則（重要）

後台登入用的是 Firebase Authentication。規則確保客人只能「送出」訂單，用 LINE 登入的客人只看得到自己的訂單；只有管理員能查看所有訂單、修改商品與儲值金。

1. Firebase 主控台 → Firestore Database → **規則**，把 `firestore.rules` 整份內容貼上。
2. 在主控台裡把兩個「請換成…管理員信箱」改成兩位管理員登入後台的信箱，按「發布」。
   這個 GitHub 專案是公開的，**真正的信箱只填在主控台，不要改進 `firestore.rules` 檔案**。
3. `firestore.rules` 有更新時，要重新貼上並發布一次。

## 免費額度

Firebase 免費方案（Spark）不需要綁信用卡、沒有使用期限。Firestore 每天可讀取 5 萬次、寫入 2 萬次，小店使用綽綽有餘。
LINE 官方帳號免費方案每月可主動傳 200 則訊息，每筆訂單約用 3 則；超過時只是訊息傳不出去，訂單與「我的訂單」照常運作。
