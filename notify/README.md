# 新訂單 Email 通知設定

網站有**新訂單**或**儲值申請**時，會用你的 Google 帳號自動寄信給管理員，並把訂單備份到一份 Google 試算表。
完全免費、不需要信用卡，只要照下面步驟設定一次（約 10 分鐘）。

## 步驟一：建立試算表與程式

1. 用管理員的 Google 帳號打開 [Google 試算表](https://sheets.google.com)，建立一份空白試算表，命名為「熵與焙 訂單」。
2. 上方選單：**擴充功能 → Apps Script**。
3. 把編輯器裡原本的程式碼全部刪掉，貼上這個資料夾裡 [`apps-script.gs`](apps-script.gs) 的**全部內容**。
4. 找到最上面這一行，把兩個「請換成…」改成兩位管理員要收通知的信箱：
   ```
   const ADMIN_EMAILS = ['請換成第一位管理員信箱', '請換成第二位管理員信箱'];
   ```
   ⚠ 只在 Apps Script 裡改就好，**不要把真正的信箱改進 GitHub 的檔案**（GitHub 專案是公開的）。
5. 按上方的 💾 儲存。

## 步驟二：授權並寄測試信

1. 在上方的函式選單選 **`sendTestEmail`**，按 **▶ 執行**。
2. 會跳出「需要授權」→ 選你的 Google 帳號。
3. 如果出現「**Google 尚未驗證這個應用程式**」：按左下角「**進階**」→「**前往（不安全）**」→「**允許**」。
   這是因為程式是你自己建立的，不是公開的 App，屬於正常現象。
4. 到管理員信箱，應該會收到一封「【測試】【熵與焙】新訂單 TEST」的信。

## 步驟三：部署成網址

1. 右上角 **部署 → 新增部署作業**。
2. 左邊齒輪「選取類型」→ **網頁應用程式**。
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」，複製「**網頁應用程式網址**」（`https://script.google.com/macros/s/……/exec`）。

## 步驟四：貼到網站後台

1. 登入網站後台 → 最下方「⚙️ 商店設定」→「📧 新訂單 Email 通知」。
2. 貼上剛剛複製的網址 → 按「💾 儲存商店設定」。
3. 按「**寄送測試通知**」，約 1 分鐘內兩位管理員都會收到測試信，就完成了！

## 常見問題

- **每天可以寄幾封？** 一般 Gmail 帳號每天約可寄給 100 位收件者。兩位管理員等於每筆訂單算 2 位，所以每天約 50 筆訂單以內都沒問題。
- **之後改了程式要重新部署嗎？** 要：部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署。網址不會變，不用改後台設定。
- **沒收到信？** 先看垃圾郵件匣；再到 Apps Script 左邊的「執行項目」查看有沒有錯誤。就算 Email 沒寄出，訂單還是會出現在後台「訂單管理」。
- **試算表裡有客人的姓名、電話、地址**，請不要把試算表分享給管理員以外的人。
